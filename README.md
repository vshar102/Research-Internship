# Research Internship- Cardiovascular Risk Assessment using Normalizing Flows

🎯 Project Overview

Developed advanced density estimation and classification solution for cardiovascular risk assessment using Normalizing Flows (MAF and Real NVP), implementing cutting-edge generative models to analyze South African Heart Disease data for improved medical diagnosis and risk stratification in clinical healthcare applications.

💼 Business Problem

Healthcare providers needed sophisticated probabilistic modeling capabilities to better understand complex feature distributions in cardiovascular risk factors, improve diagnostic accuracy beyond traditional classification methods, and enable more nuanced risk assessment for coronary heart disease prediction in clinical decision-making processes.

🔧 Technical Solution

Implemented state-of-the-art normalizing flow architectures including Masked Autoregressive Flow (MAF) and Real Non-Volume Preserving (NVP) models for density estimation on SAHeart dataset. Developed comprehensive preprocessing pipeline with categorical encoding, train/validation/test splits, and feature standardization. Built deep MAF models with MADE masking layers and Real NVP coupling layers, implementing custom PyTorch architectures with autoregressive transformations and invertible neural networks for exact likelihood computation.

📊 Key Results

Advanced density estimation framework using normalizing flows for medical data
Implementation of both MAF and Real NVP architectures with custom masking mechanisms
Probabilistic classification approach combining density estimates with class priors
Comprehensive model training with gradient-based optimization and learning rate scheduling
Joint estimation methodology for enhanced classification performance

💰 Business Impact

Enabled more sophisticated cardiovascular risk assessment through probabilistic modeling, providing healthcare practitioners with uncertainty quantification and interpretable density estimates. Foundation for improved clinical decision support systems, personalized risk stratification, and enhanced diagnostic accuracy in coronary heart disease prediction, supporting evidence-based medical practice and patient care optimization.
